02 / Proposed project

대본 옆에서 고르면,
설명에 맞춰 붙습니다.

첫 고객은 대본과 자료를 직접 준비하는 1인 정보성 영상 제작자입니다. 첫 실사용자는 저 자신입니다.

기획 · 사전 개발 준비

대본 중심 AI 영상 편집 웹서비스

대사에 맞는 이미지·반응 짤·효과음을 찾고, 화면과 소리의 등장 시점을 맞추는 반복 작업을 줄입니다. 확정한 대본과 채택한 장면을 유지하면서 필요한 부분만 수정하도록 설계합니다.

01 · 입력대본과 내 자료준비한 원고와 이미지·캡처·짤·효과음을 가져옵니다.
02 · 제안과 선택문맥에 맞는 연출비교·순서·강조에 맞는 소재를 추천하고, 선택한 요소를 문장에 연결합니다.
03 · 수정과 출력필요한 부분만 변경음성·자막·연출의 연결을 유지하며 수정하고 영상으로 내보냅니다.

편집 흐름 설명 예시

두 제품의 가격은 비슷하지만, 배터리는 A가 더 오래갑니다.
비교 화면
제공된 제품 자료를 나란히 배치하고, 가격과 배터리 항목을 비교하는 화면을 제안합니다.
강조 시점
“배터리는”이라는 대사에 배터리 항목의 강조를 연결합니다. 효과음 사용 여부와 음량은 사용자가 선택합니다.
대본 수정
대사를 바꾸면 연결된 음성·자막·연출을 갱신 대상으로 표시합니다. 사용자가 잠근 자료와 다른 장면은 유지하도록 설계합니다.

기획 이해를 위한 고정 예시입니다. 실제 AI 생성이나 영상 편집 기능이 실행되는 데모는 아닙니다.

해커톤에서 보여줄 것

60~90초 영상의 입력부터 소재 선택, 문장에 연결된 배치, 부분 수정, MP4 출력까지 구현합니다. 이용 조건을 확인한 소재를 사용하고 이미지 생성은 필요한 장면에 선택적으로 연결할 계획입니다.

직접 사용할 영상으로 검증

같은 대본과 자료로 기존 편집 방식과 작업 시간·수정 누락·재시도 비용을 비교할 계획입니다. 시간 절감 효과는 아직 측정 전이며, 본인 사용 경험과 외부 고객 수요를 구분합니다.
